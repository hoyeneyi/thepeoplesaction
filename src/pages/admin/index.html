Connect the staff portal

The website is running in static mode: pages, photos and donations work, but the live calendar, editable text, team editor and message inbox need a free Firebase project.

  1. Follow docs/ADMIN-GUIDE.md → “One-time setup” in the website repository.
  2. Paste the Firebase web config into assets/js/config.js.
  3. Deploy firebase/firestore.rules, create your staff login, and add it as an admin.
